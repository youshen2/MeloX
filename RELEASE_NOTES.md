# MeloX Release Notes / MeloX 更新日志

## iOS + Apple Watch

### 简体中文

- 增加了多声部同时唱词与独立逐字高亮
- 增加了收藏专辑入口
- 修复了蓝牙音频设备断开后播放未自动暂停的问题
- 修复了逐字歌词切换时的闪烁问题
- 优化了歌词加载性能和动效连贯性
- 完善了 TTML 歌词解析
- 优化了 Apple Watch 逐字歌词获取与回退
- 优化了播放器菜单的歌词源选择

### English

- Added simultaneous vocal parts with independent word highlighting
- Added access to favorite albums
- Fixed playback not pausing when a Bluetooth audio device disconnects
- Fixed flickering during word-synced lyric transitions
- Improved lyric loading performance and animation continuity
- Improved TTML lyric parsing
- Improved word-synced lyric fetching and fallback on Apple Watch
- Refined lyric source selection in the player menu

## macOS

### 简体中文

- 增加了 Dock 图标右键菜单的播放控制项
- 增加了多声部同时唱词与独立逐字高亮
- 增加了收藏专辑入口
- 修复了系统媒体暂停键失效的问题
- 修复了播放器收藏按钮状态未及时刷新的问题
- 修复了逐字歌词切换时的闪烁问题
- 修复了歌词优选加载期间未先显示网易云歌词的问题
- 优化了歌词加载性能和动效连贯性
- 优化了 Apple Music 样式背景的性能与显示效果
- 完善了 TTML 歌词解析

### English

- Added playback controls to the Dock icon’s context menu
- Added simultaneous vocal parts with independent word highlighting
- Added access to favorite albums
- Fixed the system media pause key not working
- Fixed delayed updates to the player’s favorite button
- Fixed flickering during word-synced lyric transitions
- Fixed NetEase lyrics not appearing while preferred lyrics load
- Improved lyric loading performance and animation continuity
- Improved Apple Music background performance and appearance
- Improved TTML lyric parsing
